# bertlclaw-proof

Operational proof workspace for BertlClaw.

Use this directory to ensure every real project creates reusable business proof: before/after evidence, deliverable examples, approval records, and publication-ready mini-cases.

## Structure

- `projects/` — one folder per project
- `library/proof-atoms/` — small reusable proof elements extracted from projects
- `library/deliverable-gallery/` — showcaseable examples of concrete outputs
- `library/claims/` — safe claim language and publication phrasing
- `library/approvals/` — approval wording and permission patterns
- `templates/` — starter files for new projects

## New project rule

Start by copying `projects/2026/_project-template/` into a new year/client slug folder and then fill:

- `README.md`
- `project.yaml`
- `05-evidence-pack/mini-case.md`
- `05-evidence-pack/proof-summary.md`
- `06-approval/approval-status.md`
- `07-publication/publication-plan.md`

# Project Setup Checklist

For every new BertlClaw proof-relevant project:

- [ ] create project folder from template
- [ ] fill `README.md`
- [ ] fill `project.yaml`
- [ ] capture initial client/context materials into `01-intake/`
- [ ] capture before-state assets into `02-before/`
- [ ] note visible bottleneck in plain language
- [ ] define likely strongest proof atom
- [ ] set initial publication target
- [ ] create first approval reminder if needed

If `02-before/` is empty after work has started, treat that as a process failure to fix immediately.

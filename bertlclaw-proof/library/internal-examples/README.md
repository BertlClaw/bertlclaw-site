# Internal Proof Examples

These are starter examples that make the proof system concrete before a larger real-project library exists.

Rules:
- Treat every file here as **internal-only** unless it is replaced with real approved material.
- These examples are **demonstrators**, not public claims about a named client.
- Reuse the structure, not the exact story, once real projects are captured.
- If an example is later replaced with a real anonymized project, preserve the format and metadata discipline.

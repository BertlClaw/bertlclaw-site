# Deliverable Gallery

This folder is for reusable examples of what BertlClaw actually produces.

Suggested categories:
- hero rewrite
- page structure
- CTA logic
- FAQ block
- messaging map
- wireframe
- HTML landing page draft
- project organization system
- documentation structure
- prioritization board

Each gallery entry should include:
- deliverable type
- source project
- short context
- why it improved the situation
- approval level
- asset path

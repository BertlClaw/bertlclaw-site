# Deliverable Gallery Cards

Reusable card copy for homepage, proof page, services, and proposals.

## 1. Hero Rewrite
- **Deliverable:** Hero + Subheadline + CTA direction
- **Shows:** how an offer becomes faster to understand
- **Typical proof:** before/after headline pair
- **Use when:** a page sounds correct but still too vague or generic

## 2. Page Structure
- **Deliverable:** section logic and reading order
- **Shows:** how BertlClaw turns information into a usable flow
- **Typical proof:** structure map, wireframe, section outline
- **Use when:** a site has content, but no strong sequencing

## 3. FAQ / Objection Handling Block
- **Deliverable:** clear answers to common questions and hesitations
- **Shows:** how trust is built with usable copy, not filler
- **Typical proof:** approved excerpt or screenshot
- **Use when:** prospects need too much extra explanation before contacting

## 4. Messaging Map
- **Deliverable:** positioning angles, headline system, offer language
- **Shows:** the strategic layer behind the final copy
- **Typical proof:** excerpt from a copy doc or message hierarchy
- **Use when:** the business sounds competent, but not distinctive enough

## 5. HTML Landingpage Draft
- **Deliverable:** implementation-ready page draft or complete landingpage
- **Shows:** that BertlClaw ships concrete assets, not just recommendations
- **Typical proof:** final section screenshot or page preview
- **Use when:** a business needs an actual page, not another abstract workshop

## 6. Priority / Documentation System
- **Deliverable:** project map, next-step order, documentation logic
- **Shows:** how scattered digital work becomes actionable structure
- **Typical proof:** board screenshot, folder map, system overview
- **Use when:** ideas, files, and open threads have become hard to work with

## Publishing note
Each card should only be used with:
- a real source project or internal demonstrator
- a documented approval status
- a visible proof type attached or referenced

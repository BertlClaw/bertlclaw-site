# Proof Atoms Library

Proof atoms are the smallest reusable business-proof units extracted from projects.

Examples:
- one strong hero before/after
- one cleaned-up CTA block
- one short structure comparison
- one deliverable screenshot
- one client-approved quote
- one problem/solution sentence pair

Why this matters:
A full case study is expensive. Proof atoms are cheap, flexible, and reusable across website sections, proposals, and sales conversations.

When adding a proof atom, record:
- source project
- what changed
- why it matters
- approval status
- where it can be reused

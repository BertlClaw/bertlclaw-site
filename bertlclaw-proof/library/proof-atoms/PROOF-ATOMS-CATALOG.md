# Proof Atoms Catalog

Starter catalog for proof atoms BertlClaw should extract repeatedly from real work.

## 1. Hero before/after
- **What it is:** old vs. revised hero framing
- **Why it matters:** makes clarity improvement visible within seconds
- **Evidence type:** screenshot pair or text diff
- **Best reuse:** proof page, homepage module, proposals

## 2. Offer-structure cleanup
- **What it is:** old section order vs. revised section logic
- **Why it matters:** shows how BertlClaw turns scattered information into readable flow
- **Evidence type:** structure list, wireframe snapshot, section map
- **Best reuse:** services page, mini-cases, sales calls

## 3. FAQ / objection block
- **What it is:** a compact FAQ or objection-handling block
- **Why it matters:** demonstrates concrete copy deliverables instead of vague strategy talk
- **Evidence type:** approved text excerpt or screenshot
- **Best reuse:** deliverable gallery, proposals, sales proof snippets

## 4. CTA logic upgrade
- **What it is:** clearer next-step framing, reduced friction, stronger call-to-action placement
- **Why it matters:** often easy to understand visually
- **Evidence type:** before/after CTA comparison
- **Best reuse:** proof page, landingpage offer section

## 5. Messaging map / copy system
- **What it is:** structured message hierarchy, angle map, or headline set
- **Why it matters:** proves strategic thinking translated into usable output
- **Evidence type:** document excerpt, screenshot, section list
- **Best reuse:** services page, sales deck, deliverable gallery

## 6. Prioritization board / project order system
- **What it is:** a cleaned-up task, topic, or documentation structure
- **Why it matters:** supports the 'digitale Ordnung & Klarheit' offer with visible evidence
- **Evidence type:** board screenshot, project map, folder tree
- **Best reuse:** use cases, proof page, internal sales examples

## 7. Final implementation snapshot
- **What it is:** approved final page, section, or deliverable screenshot
- **Why it matters:** connects thinking to actual shipped output
- **Evidence type:** live screenshot or exported final
- **Best reuse:** proof page, website cards, outreach follow-ups

## Minimum metadata per proof atom
- source project
- date captured
- problem before
- intervention
- visible difference
- approval status
- allowed reuse channels

## Rule
Extract at least one proof atom from every project that reaches a clear before/after or a concrete deliverable outcome.

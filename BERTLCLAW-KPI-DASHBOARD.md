## KPI-Review-Ritual (Erster Montag/Monat)

```
1. Zahlen sammeln (15 Min.)
   → GoatCounter öffnen → Zahlen eintragen
   → LinkedIn Analytics → Zahlen eintragen
   → EAR-Tabelle → Umsatz eintragen
   → Projektboard → Leads, Projekte eintragen

2. Trends erkennen (10 Min.)
   → Was ist besser als letzten Monat?
   → Was ist schlechter?
   → Was überrascht?

3. 1 Aktion ableiten (5 Min.)
   → Was ist der eine Hebel, den ich nächsten Monat mehr drücke?
   → In Wochenplan eintragen

4. Notiz schreiben (2 Min.)
   → 3 Sätze: Was war gut? Was war schlecht? Was ändere ich?
```

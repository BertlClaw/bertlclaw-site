# BertlClaw External Corroboration Plan

Ziel: Aus der lokalen Markenlogik eine kleine, saubere öffentliche Entity-Struktur machen, die Google und Menschen unabhängig voneinander bestätigen können.

## Priorität: lieber 3 starke Quellen als 10 halbtote Profile

Reihenfolge:

1. **GitHub Profil + Profil-README + Website-Repo**
2. **LinkedIn Personal-Profil mit sauberer BertlClaw-Erwähnung**
3. **Gravatar / Avatar-Quelle für E-Mail-gebundene Sichtbarkeit**
4. Optional: **About.me oder Bento** nur wenn wirklich gepflegt
5. Optional später: thematisch passende Erwähnungen / Gastbeiträge / Verzeichnisse

## Corroboration model

Jede externe Quelle soll möglichst dieselben fünf Kerndaten bestätigen:

- **Name:** BertlClaw
- **Betreiber:** Dominic Reisenbichler, MSc.
- **URL:** https://bertlclaw.at/
- **Region:** Austria / Österreich
- **Beschreibung:** BertlClaw ist die Projektmarke von Dominic Reisenbichler, MSc. für Landingpages, Website-Texte, Positionierung, digitale Struktur und KI-Unterstützung.

## Phase 1 — GitHub as primary trust node

### A. GitHub profile

**Display name:** BertlClaw  
**Bio:** BertlClaw ist die Projektmarke von Dominic Reisenbichler, MSc. für Landingpages, Website-Texte, Positionierung, digitale Struktur und KI-Unterstützung.  
**Website field:** https://bertlclaw.at/  
**Location:** Austria

### B. GitHub profile README

Pflichtblöcke:

- 1x kurze Markendefinition
- 1x Betreiber-Zuordnung
- 1x Link zur Website
- 1x Link zu `ueber-bertlclaw.html`
- 1x Link zu Impressum

### C. Website repo

Sofort angleichen:

- Repo Description
- Social preview image
- Pinned repo selection
- README intro

**Warum zuerst GitHub:**
GitHub ist der derzeit stärkste indexierbare, überprüfbare und schon vorhandene öffentliche Knoten von BertlClaw.

## Phase 2 — operator corroboration outside GitHub

### A. LinkedIn personal profile

Eintrag in:

- Headline oder About-Bereich
- Featured-Link zur Website
- klare Erwähnung, dass BertlClaw die Projektmarke von Dominic Reisenbichler ist

**Nicht tun:**

- keine zweite konkurrierende Markenbeschreibung
- keine komplett andere Kurzform als auf Website/GitHub

### B. Gravatar

Nutzen:

- gleiche Namens-/Bildlogik bei E-Mail-gebundenen Web-Oberflächen
- stärkt visuelle Wiedererkennbarkeit zwischen Betreiber und Marke

Felder:

- Display name: Dominic Reisenbichler / BertlClaw nur wenn sauber kombinierbar
- About: kurze BertlClaw-Zuordnung
- Website: Haupt-URL
- Profilbild: gleiches Hauptlogo oder konsistente Betreiber-/Markenlogik

## Phase 3 — second-layer corroboration

Nur wenn Phase 1 und 2 sauber live sind.

### Optional clean profile hub

**About.me oder Bento** nur falls:

- derselbe Textkanon genutzt wird
- keine veralteten Links stehen bleiben
- das Profil aktiv gepflegt wird

### Optional citation opportunities

Geeignet sind eher:

- Gastbeiträge mit Autorenbox
- Projekt-/Tool-Seiten mit Betreiberinfo
- Partner-/Freelancer-Profile
- nachvollziehbare Erwähnungen in thematisch passenden Communities

Nicht geeignet:

- Spam-Verzeichnisse
- tote Startup-Profile
- wahllose AI-Directories ohne Pflege

## Public proof corroboration

Externe Korrelation ist stärker, wenn nicht nur Marke + Name auftauchen, sondern auch nachvollziehbare Arbeit.

Deshalb mittelfristig veröffentlichen:

- Methoden-/Arbeitsweise-Seite
- anonymisierte Vorher/Nachher-Beispiele
- dokumentierte Entscheidungslogik
- konkrete Deliverables statt nur Leistungslisten

## Minimum viable external stack

Wenn nur das Wichtigste umgesetzt wird, dann dieses Paket:

1. GitHub profile live angleichen
2. GitHub profile README veröffentlichen
3. Repo description / pins angleichen
4. LinkedIn About + Featured-Link aktualisieren
5. Gravatar angleichen
6. alle Live-URLs in einer Tracking-Tabelle dokumentieren

## Done criteria

Das Paket ist erst wirklich fertig, wenn:

- mindestens 2 externe Quellen BertlClaw + Dominic + URL konsistent bestätigen
- GitHub und Website dieselbe Kernbeschreibung verwenden
- `ueber-bertlclaw.html` von mindestens einer externen Quelle direkt verlinkt ist
- kein öffentliches Profil BertlClaw widersprüchlich als App / Agent / Tool / Marke bezeichnet

## Operating rule

Ab jetzt keine neue öffentliche BertlClaw-Fläche ohne Eintrag in die Citation-/Consistency-Tabelle anlegen. Erst Kanon festhalten, dann veröffentlichen.

# BERTLCLAW-PROOF-OPS-CHECKLIST

Praktische Arbeitsvorlage pro Projekt. Ziel: Belege nicht vergessen, Freigaben sauber handhaben und aus laufender Arbeit verwertbaren Proof machen.

---

## 1. Beim Projektstart erfassen

- Interner Projektname / Alias:
- Datum / Zeitraum:
- Angebot:
  - Landingpage Sprint
  - Positionierung & Website-Texte
  - Digitale Ordnung & Klarheit
  - anderes:
- Branche / Typ:
- Ansprechperson:
- Öffentliche Nennung aktuell:
  - [ ] offen
  - [ ] nein
  - [ ] anonym möglich
  - [ ] mit Name möglich

### Kurzbeschreibung der Ausgangslage
- Was war vorher unklar, schwach oder chaotisch?
- Was blockiert konkret?
- Was soll danach besser sein?

---

## 2. Vorher-Material sichern

- [ ] Screenshot bestehender Hero / Seite
- [ ] Copy-Paste alter Headline / alter Textblöcke
- [ ] Screenshot bisheriger Struktur / Board / Dokumentation
- [ ] Link zur alten Live-Seite oder Archivstand
- [ ] Notiz: Was ist der sichtbarste Engpass?

---

## 3. Während der Arbeit sammeln

- [ ] Strukturentwurf gesichert
- [ ] Zwischenstand mit wichtigem Unterschied gesichert
- [ ] neue Headlines / Copy-Optionen gesichert
- [ ] Wireframe / HTML / Dokumentauszug gesichert
- [ ] Liste: Was wurde konkret überarbeitet?

---

## 4. Zum Abschluss sichern

- [ ] 2-4 finale Screenshots
- [ ] finaler Textauszug
- [ ] finaler Link oder Dokumentstand
- [ ] Liste gelieferter Deliverables
- [ ] 1 Satz: Was ist jetzt sichtbar besser?
- [ ] 1 Satz: Was davon ist öffentlich zeigbar?
